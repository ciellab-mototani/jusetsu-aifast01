- 作ったのは関の会社（スカイネット）で、AI（Anthropic の Claude Code）に作らせ、ChatGPT にも確認させながら進めました。

## 4. 公開のときにお願いしたいこと（ご提案の【ベース作業 A】の範囲と考えています）
1. **問い合わせフォームを、今の問い合わせ先につなぐ**（一番大事な点です）
   - 今の制作データの申し込みフォームは**見た目だけで、送信はしていません**（送信ボタンを押すと「ただいま送信の準備中です。お急ぎの方は、フリーダイヤル 0120-138-870 までお電話ください。」と出ます）。
   - フォームは `r47.js` が、`#sales-contact` へのリンク・申し込みボタンを押したときに画面の上に出しています。
   - 項目：お問い合わせ種別（無料トライアルの予約／資料請求（料金表つき）／お問い合わせ）・会社名・姓・名・メールアドレス・電話番号（ここまで必須）・お使いの書式・主な物件種別・部署名・役職・相談事項（任意）・プライバシーポリシーへの同意（必須）。今の LP のフォームの項目に、書式と物件種別（任意）を足した形です。
   - 今の LP のフォームの仕組みにつなぐ形（このフォームを生かす／今のフォームに差し替える）は、お任せします。
2. **計測タグ（アクセス解析など）を、今の LP と同じように入れる**
   - ボタンには `data-cta` の印を付けています（例：`demo`＝無料トライアルを予約、`request`＝資料請求、`-float`＝画面下に出る帯、`-hero`＝各ページの最初の画面）。押された回数を取る場合にお使いください。
3. **検索に出さない設定を外す**：全ページに `<meta name="robots" content="noindex,nofollow">` を入れています（確認用ページを検索に出さないため）。公開時に外してください。
4. **まだ入れていない物**：ページの説明文（meta description）・リンクを共有したときの絵（OGP）・タブの小さな絵（favicon）・正規の URL（canonical）。今の LP の物を引き継いでいただけますと幸いです。
5. **公開する場所**：今の LP の URL で差し替えたいと考えています。ページ間のリンクは相対の書き方（`index.html`・`features/index.html` など）です。WordPress の作りに合わせて変える必要があれば、ご相談ください。
6. **今の本番 LP の画像の差し替え**：今の本番の「仕組み」の章の画面写真（`structure_img01.png`）のファイル名に、実在の案件の地番が写っています。地番を見本の名前に置き換えた画像を添付しますので、先に差し替えをお願いできますでしょうか（新版の制作データの中の同じ画像は、置き換え済みです）。
